= aerospace-focus-app(1)
include::util/man-attributes.adoc[]
// tag::purpose[]
:manpurpose: Focus an app's window wherever it is, or open the app.
// end::purpose[]
:manname: aerospace-focus-app

// =========================================================== Synopsis
== Synopsis
[verse]
// tag::synopsis[]
aerospace focus-app [-h|--help] <app-bundle-id>|<app-name>
aerospace focus-app [-h|--help] --default-browser
aerospace focus-app [-h|--help] --default-terminal

// end::synopsis[]

// =========================================================== Description
== Description

// tag::body[]
{manpurpose}

* If the app has a window on any workspace or monitor, the command switches to that workspace and focuses the window.
  When the app has several windows, the one you used last is focused.
* If the app is already focused, the command cycles to its next window, across workspaces.
  With a single window, the command does nothing.
* If the app is running but AeroSpace sees no window of it (all windows are minimized, or the app is hidden),
  the command activates the app the way clicking its Dock icon does, which usually brings a window back.
* If the app isn't running, the command launches it.

Bind it to a key to jump straight to an app:

[source,toml]
----
[mode.main.binding]
    alt-b = 'focus-app --default-browser'
    alt-enter = 'focus-app --default-terminal'
    alt-shift-m = 'focus-app com.apple.Music'
----

To give an app a home workspace, so that its new windows open there, combine it with `on-window-detected`:

[source,toml]
----
[[on-window-detected]]
    if.app-id = 'com.google.Chrome'
    run = 'move-node-to-workspace 4'
----

// =========================================================== Options
include::./util/conditional-options-header.adoc[]

-h, --help:: Print help
--default-browser:: The app that opens web links (System Settings → Desktop & Dock → Default web browser), looked up each time the command runs.
--default-terminal:: The first installed terminal of Tern, Ghostty, kitty, Alacritty, WezTerm, iTerm2, Warp, and Terminal.

// =========================================================== Arguments
include::./util/conditional-arguments-header.adoc[]

<app-bundle-id>|<app-name>::
The app's bundle id, e.g. `com.apple.Safari`, or its name, e.g. `Safari`.
Bundle ids are matched first.
Run `aerospace list-apps` to see bundle ids of running apps.
