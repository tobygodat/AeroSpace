// =========================================================== Synopsis
== Synopsis
[verse]
// tag::synopsis[]
aerospace workspace-layout [-h|--help] [--workspace <workspace>] (<target-layout>)...

// end::synopsis[]

// =========================================================== Description
== Description

// tag::body[]
{manpurpose}

The workspace layout decides where new windows go and rebuilds the workspace tree when it changes:

* `tiles` - AeroSpace's tree of tiles and accordions. New windows join the focused window's container
* `dwindle` - Hyprland's default. A new window splits the focused window's area along its longer side, so the windows spiral
* `scrolling` - PaperWM/niri style. Windows are columns on a strip that can be wider than the screen; the strip scrolls just
  enough to keep the focused column in view. A new window is a new column next to the focused one, `scrolling-column-width`
  percent of the screen wide. `join-with left|right` stacks a window into the neighbouring column, `move left|right` moves
  between columns, `resize width` changes a column's width
* `floating` - Every window floats where it stands. Switching away tiles the windows that this layout floated;
  dialogs and windows floated with `layout floating` keep floating. `layout tiling` is refused in a floating workspace

The layout set by this command lasts until `reload-config`, which applies `default-workspace-layout`,
`scrolling-column-width` and the `[workspace-layout]` table from the config again. The Layouts pane of the Keybindings
window edits all three.

// =========================================================== Options
include::./util/conditional-options-header.adoc[]

-h, --help:: Print help

--workspace <workspace>::
include::./util/workspace-flag-desc.adoc[]

// =========================================================== Arguments
include::./util/conditional-arguments-header.adoc[]

<target-layout>::
Possible values: `tiles|dwindle|scrolling|floating|next`.
`next` cycles to the following layout (in that order) and can't be combined with other values.
+
If several `<target-layout>` are supplied, then the first one that doesn't describe the current layout is applied.

// =========================================================== Examples
include::./util/conditional-examples-header.adoc[]

* Cycle the layout of the focused workspace: +
`aerospace workspace-layout next`

* Toggle between `dwindle` and `floating`: +
`aerospace workspace-layout dwindle floating`

* Make workspace 2 float: +
`aerospace workspace-layout --workspace 2 floating`
